# NavFocus App Icon Prompt

## Icon Design Prompt for AI Generation

A minimalist iOS app icon for a navigation app called NavFocus, designed for the US market. The icon features a stylized compass arrow pointing north, combined with a subtle route path line, set against a clean gradient background transitioning from deep blue (#007AFF) to vibrant purple (#5856D6). The compass arrow is white with a slight glow effect. The design follows Apple's Human Interface Guidelines for app icons - flat, no transparency, no text, no photos, rounded corners implied (not drawn). The icon should feel modern, professional, and trustworthy, appealing to adults with ADHD who need focused navigation assistance. Style: clean, geometric, Apple-inspired minimalism. Size: 1024x1024 pixels, flat design, no shadows, no 3D effects.

## Technical Requirements
- Size: 1024x1024 pixels
- Format: PNG
- Flat design (no transparency, no 3D, no shadows)
- Apple HIG compliant
- No text in icon
- No photo elements
